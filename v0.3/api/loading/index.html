    Data Loading

    Every analysis class loads telemetry through TelemetryLoader, so all of them see the same columns. The loader:

    1. reads one source: a DataFrame, a .csv or .parquet file, or a SQL template;
    2. renames known synonyms to the canonical names, for example giga_id_school to school_id_giga;
    3. merges official pins as govt_latitude and govt_longitude when the telemetry does not already have them;
    4. converts UTC timestamps to local time at the facility and adds the operational-hours flags.

    It never fills detected_latitude or detected_longitude from IP coordinates in client_info. Rows without a Wi-Fi location keep null coordinates and are dropped later by the spatial classes.

    Column Contract

    Required after canonicalisation:

    Column Meaning
    school_id_giga Facility identifier (giga_id_school is accepted)
    device_id Device identifier; may be null for older app versions
    detected_latitude, detected_longitude Google Wi-Fi geolocation result, or null
    created_timestamp UTC time of the measurement

    Added by the loader:

    Column Meaning
    govt_latitude, govt_longitude Official pin, when one is found
    tz_name IANA time zone of the facility
    local_created_timestamp, local_date, local_hour, local_day_of_week Local time fields
    is_weekday Monday to Friday
    is_operational_hours 08:00:00 to 19:59:59 local time

    Optional Wi-Fi columns are renamed when present: detected_bssid to detected_wifi_bssid, detected_ssid to detected_wifi_ssid, and detected_wifi_signal to wifi_signal_dbm.

    TelemetryLoader

    TelemetryLoader(sql_dir=None)

    Load spatial telemetry into the canonical analysis frame.

    Provide exactly one source: telemetry_df, file_path, or query_name with query_params. A .csv or .parquet file is read from file_path. query_name is a template stem under sql/ formatted with query_params.

    When govt_latitude is already on the frame, school coordinates and both clients are skipped. Otherwise pins are merged from schools_df, or from delta_store.load_table(country_iso3) when schools_df is omitted. Local-time enrichment is skipped when local_created_timestamp, local_hour, and is_operational_hours are already present.

    Parameters:

    Name Type Description Default
    sql_dir Optional[Union[str, Path]]

    Directory of .sql templates. Defaults to the repository sql/ directory.

    		 None

    load(telemetry_df=None, *, file_path=None, query_name=None, query_params=None, country_iso3=None, schools_df=None, timestamp_col='created_timestamp', db=None, delta_store=None)

    Load, canonicalize, pin-merge, and locally time-enrich telemetry.

    Parameters:

    Name Type Description Default
    telemetry_df Optional[DataFrame]

    In-memory measurements. Mutually exclusive with file_path and query_name.

    		 None
    file_path Optional[Union[str, Path]]

    .csv or .parquet ledger path.

    		 None
    query_name Optional[str]

    SQL template stem, without the .sql suffix.

    		 None
    query_params Optional[Mapping[str, Any]]

    Values for the SQL template placeholders.

    		 None
    country_iso3 Optional[str]

    ISO3 code passed to delta_store.load_table. Defaults to query_params["country_iso3"] when omitted.

    		 None
    schools_df Optional[DataFrame]

    Official school metadata. Used only when the telemetry frame does not already contain govt_latitude.

    		 None
    timestamp_col str

    UTC timestamp column read by the timezone enricher.

    		 'created_timestamp'
    db Any

    Database client with test_connection and read_sql_to_dataframe. Constructed with DBConnection() when a query is requested and this is omitted.

    		 None
    delta_store Any

    Delta Sharing client with load_table. Constructed with DeltaSharingDataStore() when school pins must be loaded and this is omitted.

    		 None

    Returns:

    Type Description
    DataFrame

    A copy of the telemetry frame with canonical identifiers, optional Wi-Fi columns under their canonical names, govt_latitude and govt_longitude when a schools row matches, and local-time columns tz_name, local_created_timestamp, local_date, local_hour, local_day_of_week, is_weekday, and is_operational_hours.

    Raises:

    Type Description
    ValueError

    If the source count is not exactly one, the file suffix is unsupported, school pins cannot be resolved, or required columns are missing.
    ConnectionError

    If db.test_connection() returns false.

    Helper Functions

    canonicalize_telemetry_columns(telemetry_df)

    Rename known telemetry synonyms to the canonical column contract.

    is_school_hours is renamed to is_operational_hours only when the canonical flag is absent. Official latitude / longitude pins already merged onto a frame are renamed to govt_latitude / govt_longitude only when those govt columns are absent. The input frame is not modified.

    Parameters:

    Name Type Description Default
    telemetry_df DataFrame

    Telemetry measurements from SQL, a file, or a caller.

    		 required

    Returns:

    Type Description
    DataFrame

    A copy of telemetry_df using canonical column names.

    prepare_schools_frame(schools_df)

    Reduce a schools table to the join key and official coordinates.

    The schools table, whether supplied by the caller or loaded from Delta Sharing, must contain latitude and longitude. Those columns are renamed to govt_latitude and govt_longitude. giga_id_school is renamed to school_id_giga when that is the identifier column.

    Parameters:

    Name Type Description Default
    schools_df DataFrame

    Official school metadata, one row per facility.

    		 required

    Returns:

    Type Description
    DataFrame

    Deduplicated columns school_id_giga, govt_latitude, and govt_longitude.

    Raises:

    Type Description
    ValueError

    If the identifier or coordinate columns are missing.

    enrich_telemetry_with_local_time(telemetry_df, timestamp_col='created_timestamp')

    Convert UTC telemetry timestamps into local device time.

    Official school coordinates must already be on the frame as govt_latitude and govt_longitude. This function maps each school_id_giga to an IANA timezone, converts timestamp_col from UTC, and sets the GigaMeter operational window (08:00-19:59 local time).

    Parameters:

    Name Type Description Default
    telemetry_df DataFrame

    Canonical telemetry frame.

    		 required
    timestamp_col str

    UTC timestamp column to convert.

    		 'created_timestamp'

    Returns:

    Type Description
    DataFrame

    A copy of telemetry_df with tz_name, created_timestamp_utc, local_created_timestamp, local_date, local_hour, local_day_of_week, is_weekday, and is_operational_hours.

    Raises:

    Type Description
    ValueError

    If school_id_giga is missing.

    build_school_timezone_map(telemetry_df)

    Construct a dictionary mapping school_id_giga to an IANA timezone string.

    The frame must already use canonical identifiers and, when official pins are available, govt_latitude / govt_longitude. Facilities are deduplicated first so spatial lookup is O(N_schools) rather than O(N_rows).

    Name Type Description Default

    Returns:

    Type Description

    Mapping of school_id_giga to an IANA timezone name.

    Raises:

    Type Description
    ValueError

    If school_id_giga is missing.
