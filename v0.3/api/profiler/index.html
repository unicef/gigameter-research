    SpatialProfiler

    Pillar 2: tags hotspots and mobile BSSIDs, builds fix events, and selects one anchor cluster per facility. The rules are in Blueprint Section 5.

    SpatialProfiler(telemetry_df=None, *, file_path=None, query_name=None, query_params=None, country_iso3=None, schools_df=None, timestamp_col='created_timestamp', db=None, delta_store=None, config=DEFAULT_CONFIG)

    Spatial analytics engine for GigaMeter telemetry.

    On load, every row is tagged with:

    • is_hotspot_ssid: the SSID matches config.hotspot_ssid_pattern.
    • is_laa_bssid: the BSSID is a locally administered MAC (evidence only).
    • is_mobile_bssid: the BSSID's accuracy-gated, non-carried fix events form two or more clusters that each span bssid_mobility_min_cluster_days.
    • is_mobile_hotspot: is_hotspot_ssid or is_mobile_bssid.

    build_facility_spatial_summary then clusters each facility's anchor-window fix events and selects one anchor cluster.

    Load a canonical telemetry frame, tag hotspots, and build fix events.

    Provide exactly one of telemetry_df, file_path, or query_name. School-pin merge and local-time enrichment are performed by TelemetryLoader before tagging.

    summarize_governance()

    Summarize ledger quality for the governance metric cards.

    Counts are taken from the full frame held by this profiler, including rows without coordinates. Percentages are rounded to one decimal. A zero row count yields 0.0, except operational_hours_pct, which is 100.0 when the flag is absent or there are no rows.

    Returns:

    Type Description
    Dict[str, Any]

    Total records, ambient-scan and hotspot shares (split into SSID pattern and moving router), mean and median location accuracy in meters, the operational-hours share, fix-event and carried-row counts, facility and device counts, and the local date range.

    build_bssid_profiles()

    One row per school and non-null BSSID.

    Returns:

    Type Description
    DataFrame

    Observation, fix-event, and carried counts, active days, devices, operational-hours split, mean accuracy, hotspot and mobility flags, and the BSSID's coordinate tuples.

    build_facility_spatial_summary(device_events=None)

    Cluster each facility's anchor-window fix events and pick its anchor.

    Anchor-window events are non-carried fix events inside operational hours on configured workdays, from all devices, with or without a BSSID. DBSCAN uses anchor_eps_m and a minimum of one event, so every event belongs to a cluster and support decides which clusters count. Each configured strategy proposes one cluster; agreement, then a registry-name match, resolves the anchor. A cluster name-matches when SSIDs matching the registry name are seen on at least min_support_device_days of its device-days.

    Parameters:

    Name Type Description Default
    device_events Optional[DataFrame]

    Output of MobilityAnalyzer.build_device_event_table. Needed only for the stationary_first strategy.

    		 None

    Returns:

    Type Description
    DataFrame

    One row per facility with anchor centroid (empirical_centroid_lat, empirical_centroid_lon), anchor support, strategy candidates, agreement, resolution, split distance between supported clusters, hotspot event share, and provenance. The anchor centroid is empty when the strategies disagree and no name match resolves them, or when the facility has no anchor-window events. Cluster details are kept on self.facility_clusters and labelled events on self.facility_events.
